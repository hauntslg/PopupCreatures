# Popup Creatures
A collection of projects that were supposed to be stupid memes and ended up here instead \
Each project will have a little notes file with what i learned and improved.

## Projects

### Nazrin
Draws a wild 「いらっしゃいませ」 onto the screen 

Built using:
- Visual Studio 2026
- .NET10 SDK
- WPF
- Microsoft WebView2

Features:
- Transparent browser source using Microsoft WebView2
- Transparent video
- Synchronised audio using MediaPlayer

---

### Teto
Draws Teto who fittingly says "Teto" before vanishing

Built using:
- Visual Studio 2026
- .NET10 SDK
- Windows API
- GDI+
- NAudio

Features:
- Native Windows implementation using C# with the Windows API
- Transparent layered windows using GDI+
- Embedded audio playback using NAudio
- PNG sprite rendering

---

Open either solution in Visual Studio and build normally
